# SlotBot Landing Page

High-Tech Interactive Landing Page for **SlotBot** (`@zapishis_app_bot`) — Telegram scheduling platform for beauty masters, psychologists, tutors, trainers, and service specialists.

## Tech Stack
- HTML5 / CSS3 (AuthKit & Apple Keynote Dark Glassmorphism)
- Tailwind CSS
- Lucide Icons
- Vanilla JS (Interactive Phone Simulator & 7-Niches Switcher)

## Live Preview
- Open `index.html` in your browser.
- Or deploy to GitHub Pages: `Settings -> Pages -> Branch: main -> / (root) -> Save`.
